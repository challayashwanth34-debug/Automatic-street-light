💡 Automatic Street Light System

📌 Project Overview

The Automatic Street Light System is an Arduino-based project that automatically controls street lights depending on the surrounding light intensity.

The system uses an LDR (Light Dependent Resistor) sensor to detect the brightness of the environment. When darkness is detected, the street light automatically turns ON. During daytime, the light turns OFF.

🎯 Objectives

- Reduce electricity consumption.
- Automate street light operation.
- Minimize manual switching.
- Improve energy efficiency.
- Develop a smart lighting system.

🛠️ Components Required

- Arduino Uno
- LDR Sensor
- LED
- Resistors
- Connecting Wires
- Breadboard

⚙️ Technologies Used

- Arduino
- Embedded C / C++
- Wokwi Simulator

🔄 Working Principle

1. The LDR sensor detects the surrounding light intensity.
2. Arduino reads the sensor values.
3. When the environment becomes dark, Arduino switches ON the LED.
4. When sufficient light is detected, Arduino switches OFF the LED.
